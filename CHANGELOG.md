# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-11-11

- Initial open-source release of LogForge
- FastAPI management API with health, status, entities, generators, and template endpoints
- Click-based CLI for configuration bootstrap, entity registry operations, template management, and generator control
- Entity registry with validation, auto-save, and backup rotation
- Template loader, renderer, validator, and community client integration
- Generator engine with frequency control, output manager, and state tracking
- Console and file output handlers with retry/backoff support
- Integration and unit test suites covering API surface, CLI workflows, registry operations, templates, and generator execution
- Dockerfile and docker-compose examples for containerized deployments
- Example configurations, entity registry bundle, and template packs for rapid evaluation
- Template development guide and expanded README documentation
